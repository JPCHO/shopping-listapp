# 🛒 Shopping List App

아이템 추가·삭제·체크 기능을 갖춘 쇼핑 리스트 웹 앱입니다.

## 실행 방법

`index.html` 파일을 브라우저에서 바로 열면 됩니다. 서버나 빌드 과정 없이 동작합니다.

## 기능

| 기능 | 설명 |
|------|------|
| 아이템 추가 | 입력 후 `＋` 버튼 또는 `Enter` |
| 체크 | 아이템 클릭 → 완료 표시 (취소선 + 보라색 체크) |
| 삭제 | 각 항목의 `✕` 버튼 |
| 필터 | 전체 / 미완료 / 완료 탭 전환 |
| 일괄 삭제 | 완료된 항목 한 번에 삭제 |
| 영속성 | `localStorage` 저장 — 새로고침 후에도 목록 유지 |

## 기술 스택

- 순수 HTML / CSS / JavaScript
- 외부 라이브러리·프레임워크 없음
- `localStorage` API로 데이터 영속성 구현
